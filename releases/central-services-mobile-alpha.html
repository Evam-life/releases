    Central Services Mobile changelog - Alpha¶

    Warning

    You are viewing the Alpha releases of Central Services Mobile (Android and iOS).

    2.7.0 RC1¶

    2026-08-14

    Highlights¶

    • Improved the map experience with overlays and easier controls: The map app now allows users to add overlays, track units, manage custom map layers, and benefit from more user-friendly buttons.

    • Fixed an issue where deleted users’ callsigns remained unavailable: Now, when a user is deleted, their callsign is freed and can be reused by others.

    2.6.0 RC1¶

    2026-07-10

    Highlights¶

    • Fixed an issue where images with capitalized file extensions (like .PNG) could not be viewed: Now, image files with capitalized extensions appear correctly instead of being shown as generic files.

    • Location sharing on iOS: Implemented continuous location sharing to the CAD (as AVL data) based on current user status. This feature was previously only available on the Android version of Central Services, it is now available on iOS too.

    2.5.0 RC2¶

    2026-07-03

    Highlights¶

    • Added the ability for users to select their own incident notification sounds in CS mobile: Users can now choose different alert tones for new incidents through the settings menu, making notifications more customizable and user-friendly

    Additional changes¶

    • Fixed an issue where accept/dismiss buttons disappeared after demobilizing recipients: Now, when one recipient is demobilized from a case, the accept/dismiss buttons remain visible for other active users as expected

    2.5.0 RC1¶

    2026-06-26

    Highlights¶

    • Users can now see all assigned resources for each incident: The list displays callsigns and shows whether each resource is mobilised or demobilised, sorted for quick identification and color-coded for clarity

    2.4.0 RC1¶

    2026-06-12

    Highlights¶

    • Resolved an issue with message permissions: Users without the proper permissions will no longer see the stop message button, preventing unauthorized message sending and improving user experience

    2.3.0 RC1¶

    2026-05-29

    Highlights¶

    • Fixed an issue where tapping an incident notification did not show incident details: Now, tapping a notification will display the correct incident information instead of just the list.

    • Fixed an issue where opening a new message notification did not show the chat group: Now, when you tap a new message notification, you are taken directly to the conversation, even after closing the app.

    • Improved notifications for images sent by administrators: The app now displays the sender’s name instead of their email address in notifications for images sent by administrators without a callsign.

    Additional changes¶

    • Improved system monitoring and reporting for better support: Added enhanced logging to help support teams diagnose and resolve common problems more quickly.

    2.2.0 RC1¶

    2026-05-21

    Highlights¶

    • General security and performance improvements: Ongoing enhancements were made to keep the system safe and efficient

    2.1.0 RC2¶

    2026-05-07

    Highlights¶

    • Improved message alignment for admins in chat: Fixed an issue where messages sent by admins without a callsign might not appear on the correct side of the chat, causing confusion when more than one admin is present. Now, your sent messages will consistently appear opposite from others as expected

    2.1.0 RC1¶

    2026-05-06

    Highlights¶

    • Added a whole new app - Closures: Users can now add and view road restrictions, such as closures and blockages. These blockages will be visible in Vehicle Services’ Navigation app and Vehicle Services will avoid routing the user through them, making navigation more reliable and keeping you in control.

    • Expanded the incident management options for Admin users: Administrators in the system now have an overview of every active incident, improving oversight and response coordination. They can see incident details, turnout, as well as participate in the associated incident chat groups and incident command functions.

    Additional changes¶

    • Newest items always appear at the top: The lists in chat and command apps now show the most recent items first, making it easier to stay up to date

    • Cleaner mobile document viewing: The issue with having two back buttons when viewing PDFs on mobile devices has been fixed

    2.0.0 RC3¶

    2026-04-15

    Highlights¶

    • Easier to manage incidents in CS mobile: You can now accept or dismiss an incident directly from the incident view

    • Better visual design: Labels for incident status (active, pending, dismissed) and list items have been updated for a clearer and more consistent look, making information easier to understand

    • Customizable options for organizations: Organizations can now choose to hide the dismiss button if they prefer

    • Templated headings and subheadings: The main titles and descriptions for incidents can now be customized via settings to better match organizational workflows and needs.

    2.0.0 RC1¶

    2026-04-10

    Highlights¶

    • You can now see and change your current status and callsign in the top bar: This makes it easier for users to stay informed and in control of their status and vehicle assignment. By clicking the new buttons, the user can at any time or place in the app change their callsign or status.

    Additional changes¶

    • A warning banner appears when a user attempts to change status without a callsign: The app informs users that a callsign must be selected before updating status.

    • The status selection menu has an updated design: The app presents a clearer and more user-friendly way to choose a status.

    1.5.2 RC1¶

    2026-03-17

    Highlights¶

    • Code quality improvements: Applied Prettier to all code, will now run checks for typescript, eslint and prettier in pipelines.

    • Removed skip button from onboarding: If customers skipped a permission check on IOS first time, they would not be able to enable it later.

    • No more double notifications: On IOS, each notification would be shown twice; one as critical, one normal. This has been fixed.

    1.5.1 RC2¶

    2026-03-03

    Highlights¶

    • Fixed map not showing properly After allowing location permission, the map now displays your position correctly

    • Improved map behavior when sending status: The map no longer reloads and looks broken when you send a status

    1.5.1 RC1¶

    2026-02-27

    Highlights¶

    • Improved map: Fixed an issue where the map on the home page and incident page would sometimes be blue.

    • Better handling of permissions: Fixed a bug where the user would not be alerted properly if they didn’t have the correct permissions.

    Additional changes¶

    • Improved UI: Fixed an issue on the call-sign folder selection where the search bar is too large for the screen.

    • Fixed notifications: Fixed an issue where when a user logs out then back in as another user, they would receive double notifications.

    1.5.0 RC2¶

    2026-02-20

    Highlights¶

    • Better Info App translation: “Current” tab was changed to “Temporary”

    • Improved handling of call sign change: Fixed an issue when changing a call sign will ot result in the call sign being changed when sending messages in the Chat App.

    Additional changes¶

    • Removed logging in Sentry: Removed logging in Sentry to remove the performance drop.

    1.5.0 RC1¶

    2026-02-06

    Highlights¶

    • Added support for call sign folders: Call signs will now be listed showing how they are grouped by folder name, in a similar fashion as what is done in Vehicle Services.

    Additional changes¶

    • Added additional logs to the application: We have added extra logs to better help you in case of question or support request.

    1.4.2 RC1¶

    2026-02-03

    Highlights¶

    • Improved the Chat app stability: The Chat App was rewritten to be more robust and handle better loss of connection.

    • Added more styling options to chat messages: We have added support for sending and receiving messages with richer styling options such as bold and italics.

    • Improved the app performance and offline behavior: The app performance has been significantly improved through the use of caching, which also adds that it is now possible to keep accessing the online data (turnout, info) that was previously viewed even if the device goes offline or with low connectivity

    • Pager functionality for Android: Implemented continuous location sharing to the CAD (as AVL data) on CS Android only based on current user status.

    Additional changes¶

    • Fixed issue with message display: Fixed an issue where the Chat App would display messages with new lines as a long single line instead, which made them harder to read

    • Fixed an issue with missing data: In previous versions, the app could fail at displaying the favourites apps in the bottom bar as well as the notification settings. This could be confusing to the user as it seemed like these were reset. This new version should fix this issue.

    1.4.1 RC1¶

    2025-12-29

    Highlights¶

    • Improved the offline and low-connection functionality: The Mobile app now stores more data locally on the device to better handle the scenarios in which connectivity is suboptimal, the data is shown in its previous state until connectivity is back again.

    Additional changes¶

    • Fixed issue with favourite apps and notification settings not showing correctly: The previous versions had an issue where the favourite apps and notification settings would not show until the app was restarted, which could lead the user to think they were reset. This is now fixed.

    • Stability and performance improvements: The general stability and performance of the app was improved.
