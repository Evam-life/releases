    Central Services Cloud changelog - Alpha¶

    Warning

    You are viewing the Alpha releases of Central Services Cloud.

    4.8.0 RC1¶

    2026-07-17

    Highlights¶

    • Expanded support for handling GD92 messages tied to incidents: The system can now process a wider range of GD92 fire message formats, improving flexibility and making it easier for more users to manage incident information. This update vastly enhances the existing possibilities with GD92 Type 11 messages, allowing for richer data displays in Vehicle Services and Central Services when CADs support it.

    • Improved speed when loading case lists for admin users: Admin users in the Cases app now experience faster performance when checking large lists of cases, helping them access incident information more quickly from Central Services Mobile and Web.

    Additional changes¶

    • Fixed delays in health monitoring alerts: Reliability of health monitoring alerts has been improved, so notifications of possible issues arrive more quickly and accurately, improving our responses to potential incidents.

    4.7.0 RC1¶

    2026-07-10

    Highlights¶

    • Fixed an issue where images with capitalized file extensions (like .PNG) could not be viewed: Now, image files with capitalized extensions appear correctly instead of being shown as generic files.

    • Location sharing on iOS: Implemented continuous location sharing to the CAD (as AVL data) based on current user status. This feature was previously only available on the Android version of Central Services, it is now available on iOS too.

    4.6.0 RC2¶

    2026-07-03

    Highlights¶

    • Fixed an issue where accept/dismiss buttons disappeared after demobilizing recipients: Now, when one recipient is demobilized from a case, the accept/dismiss buttons remain visible for other active users as expected

    Additional changes¶

    • Improved CS cloud stability: The system now better manages its memory, reducing the risk of slowdowns or interruptions in service

    4.6.0 RC1¶

    2026-06-26

    Highlights¶

    • Users can now see all assigned resources for each incident: The list displays callsigns and shows whether each resource is mobilised or demobilised, sorted for quick identification and color-coded for clarity

    4.5.0 RC1¶

    2026-06-12

    Highlights¶

    • Resolved an issue with message permissions: Users without the proper permissions will no longer see the stop message button, preventing unauthorized message sending and improving user experience

    Additional changes¶

    • Fixed a bug affecting system alerts: Adjustments were made so that health monitoring now works reliably and false alarms about system downtime are avoided. This ensures uptime notifications are accurate

    4.4.0 RC1¶

    2026-06-05

    Highlights¶

    • Developed a bridge to connect cloud services with legacy systems: A solution was built to ensure reliable, secure communication between cloud and on-premise systems, supporting essential functions like mobilising, updating status, and ending incidents

    4.3.0 RC1¶

    2026-05-29

    Highlights¶

    • Improved notifications for images sent by administrators: The app now displays the sender’s name instead of their email address in notifications for images sent by administrators without a callsign.

    4.2.0 RC1¶

    2026-05-21

    Highlights¶

    • Fixed a rare issue with group permissions update: The Admin app could, under some conditions, reject an app permission update for a user group with the reason that not enough licenses were available, despite the fact enough licenses were available. This is now fixed.

    Additional changes¶

    • Added more detailed logs to improve error monitoring: New logs were included to help identify and diagnose issues more easily in the future

    • General security and performance improvements: Ongoing enhancements were made to keep the system safe and efficient

    4.1.0 RC1¶

    2026-05-06

    Highlights¶

    • Added a whole new app - Closures: Users can now add and view road restrictions, such as closures and blockages. These blockages will be visible in Vehicle Services’ Navigation app and Vehicle Services will avoid routing the user through them, making navigation more reliable and keeping you in control.

    • Expanded the incident management options for Admin users: Administrators in the system now have an overview of every active incident, improving oversight and response coordination. They can see incident details, turnout, as well as participate in the associated incident chat groups and incident command functions.

    Additional changes¶

    • Fixed default configuration for the incident subheading: The subheading in the incidents list and incident details will be as intended without additional configuration changes

    3.8.2 RC2¶

    2026-03-03

    Highlights¶

    • Added new settings for tuning the turnout presentation for TETRA user: We have added new settings to support the customization of the turnout for TETRA users in a future release of Vehicle Services.

    3.8.2 RC1¶

    2026-02-27

    Highlights¶

    • Added the required backend to fix the Mobile app issue with double notification: We recently fixed an issue where Central Services would receive double Push notifications, and this new release of Central Services Cloud adds support to enable this fix.

    3.8.0 RC2¶

    2026-02-16

    Highlights¶

    • Improved logging of communication with the CAD: Now we make sure all logs for communication between CS and the CAD arrive in Sentry.

    3.7.1 RC2¶

    2026-01-29

    Highlights¶

    • Pager functionality backend support: Added the server-side support for receiving position updates from Central Services mobile and forwarding them to the CAD as AVL data.

    • Added support for formatting GD92 Text messages: GD92 Text messages that are sent by the CAD can now include line breaks and these will be rendered correctly.

    3.7.0 RC1¶

    2025-12-11

    Highlights¶

    • Cleaned up the application structure: The Central Services Web app was reworked to be more robust, the breadcrumb system was notably cleaned up to be more visually consistent.

    Additional changes¶

    • Fixed an issue with PDF viewing in the Info App: Viewing PDFs inside the Info App could sometimes have visual glitches if the page was reloaded while viewing the PDF. This should now be fixed.
