# Vehicle Services: Info App changelog - Alpha

`````{warning}
You are viewing the Alpha releases of the Info Certified App.
`````

## 1.0.11

2026-07-17

### Highlights

* **Optimised image handling:** The app now manages info cards with many pictures more smoothly, and images load faster, especially when you are offline.
* **Improved offline access:** PDF files included in recommended info cards are now available offline.

## 1.0.10

2026-07-10

### Highlights

* **Fixed an issue where images with capitalized file extensions (like .PNG) could not be viewed:** Now, image files with capitalized extensions appear correctly instead of being shown as generic files.

## 1.0.9

2026-07-03

### Highlights

* **Fixed a crash when loading large PDF files:** Previously, loading big PDF documents in the info app on Vehicle Services could cause the whole system to crash. Now, larger PDFs load successfully without causing any problems.

## 1.0.8

2026-02-16

### Highlights

* **Updated the application text for clarity:** Changed the "current" tab to "temporary" for English users based on your feedback.

## 1.0.7

2025-08-06

### Highlights

* **Improved the overall navigation within the app:** The navigation in the Info CA was reworked to be more natural and less rigid: going back from an info card now brings you back to where you were before instead of always in the "All info" page. Going back from an info card that you found while searching with the search box brings you back to the search view with your search term written in.

### Additional changes

* **Fixed issue with back button in Info viewing page:** Going back from an info card now brings you back to the page you were into, instead of always the first one.
