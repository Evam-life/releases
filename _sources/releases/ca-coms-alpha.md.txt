# Vehicle Services: COMS App changelog - Alpha

`````{warning}
You are viewing the Alpha releases of the COMS Certified App.
`````


## 1.7.0

2026-06-26

### Highlights

* **Improved intercom for both tablets in the ambulance:** The mute button for intercom is now synchronized between the driver and patient areas, so muting in one place mutes everywhere, making communication smoother and more reliable.
* **Increased responsiveness:** The main tab selection buttons are now easier to press, providing a smoother
  user experience (especially while on the go).
* **Page selection behaviour:** Upon opening the application the app will now default to the favourites page when not in
  a call, or the keypad page when in an active phone or radio call.
* **Easier audio switching:** It is now easier to switch between speaker and headphones during a call. Plugging in
  headphones will automatically route call audio to them.

### Additional changes

* **Performance improvements:** Reduced the size of the app by half, resulting in far better overall
  performance.
* **Call notification stability:** Incoming call alerts are now more stable, preventing missed or flickering
  notifications when moving between pages or while the app is in the background.
* **Clearer phone number formatting:** Phone numbers now appear in a clearer, more readable format.
* **Additional translations:** Added missing translations to improve clarity.

## 1.5.1

2026-03-09

### Highlights

* **Reverted to previous behaviour when opening the app:** Keypad tab will only be shown when accepting a call (if configured to do so).

## 1.5.0

2026-03-04

### Highlights

* **Improved automatic page selection:** Upon opening COMS, the app will now default to the keypad page when the user has a call or the favourites tab when there is no active call.
* **Better call id handling:** The app will now show "no caller ID" when the incoming phone number is unknown.

### Additional changes

* **Improved the folder navigation:** The back button for folders is now much easier to click thanks to a larger touch area.
* **Fixed the notification icon:** The icon in the COMS notification now shows the correct icon.

## 1.4.0

2026-01-29

### Highlights

* **The app can now open automatically and show the Keypad page upon receiving a TETRA or Phone call:** When using the setting introduced in 1.3.0, COMS will now automatically open and display the keypad page upon receiving a call.

## 1.3.2

2025-05-21

### Highlights

* **Fixed an issue with PTT when using a Motorola radio:** A bug was introduced in the previous version that could lead to the PTT signal being held on after answering an incoming Simplex call when using a Motorola radio, it should now be fixed.

## 1.3.0

2025-05-20

### Highlights

* **Added a setting to automatically open the app upon accepting a Phone or TETRA call:** It is now possible to configure COMS to automatically open upon accepting a Phone call, a TETRA call, or both. The behavior can be customized as usual through the [COMS Configuration Tool](https://www.coms-configuration-tool.portal.evam.life/).
