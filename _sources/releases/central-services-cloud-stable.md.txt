## 4.8.0 

2026-07-21

### Highlights

* **Expanded support for handling GD92 messages tied to incidents:** The system can now process a wider range of GD92 fire message formats, improving flexibility and making it easier for more users to manage incident information. This update vastly enhances the existing possibilities with GD92 Type 11 messages, allowing for richer data displays in Vehicle Services and Central Services when CADs support it.
* **Improved speed when loading case lists for admin users:** Admin users in the Cases app now experience faster performance when checking large lists of cases, helping them access incident information more quickly from Central Services Mobile and Web.

## 4.7.0

2026-07-14

### Highlights

* **Fixed an issue where images with capitalized file extensions (such as .PNG) could not be viewed:** Images with capitalized file extensions now display correctly instead of appearing as generic files.
* **Location sharing on iOS:** Implemented continuous location sharing to the CAD (as AVL data) based on current user status. This feature was previously only available on the Android version of Central Services, it is now available on iOS too.

## 4.6.0

2026-07-06

### Highlights

* **Users can now see all assigned resources for each incident:** The list displays callsigns and shows whether each resource is mobilised or demobilised, sorted for quick identification and color-coded for clarity
* **Fixed an issue where accept/dismiss buttons disappeared after demobilizing recipients:** Now, when one recipient is demobilized from a case, the accept/dismiss buttons remain visible for other active users as expected

### Additional changes

* **Improved CS cloud stability:** The system now better manages its memory, reducing the risk of slowdowns or interruptions in service

## 4.5.0

2026-06-15

### Highlights

* **Resolved an issue with message permissions:** Users without the proper permissions will no longer see the stop message button, preventing unauthorized message sending and improving user experience

### Additional changes

* **Fixed a bug affecting system alerts:** Adjustments were made so that health monitoring now works reliably and false alarms about system downtime are avoided. This ensures uptime notifications are accurate

## 4.4.0

2026-06-09

### Highlights

* **Developed a bridge to connect cloud services with on-premise legacy systems:** A solution was built to ensure reliable and secure communication between cloud and on-premise systems, supporting essential functions such as mobilising, status updates and ending incidents.

## 4.3.0

2026-06-01

### Highlights

* **Improved notifications for images sent by administrators:** Notifications for images sent by administrators without a callsign now display the sender's name instead of their email address.

## 4.2.0

2026-05-26

### Highlights

* **Fixed a rare issue with group permissions updates:** Resolved a rare issue where The Admin app could incorrectly reject app permission updates for a user group due to license availability.

### Additional changes

* **Added more detailed logs to improve error monitoring:** Additional logs have been added to help identify and diagnose issues more effectively.
* **General security and performance improvements:** Ongoing improvements have been made to enhance system security, stability, and performance.

## 4.1.0

2026-05-11

### Highlights

* **Added the new Closures app:** Users can now add, view and edit road restrictions, such as closures and blockages. These restrictions are visible in Vehicle Services' Navigation app and routes will automatically avoid affected areas to improve routing reliability and situational awareness.
* **Expanded incident management options for Admin users:** Administrators can now view all active incidents for improved oversight and response coordination. They can see incident details, turnout, as well as participate in the associated incident chat groups and incident command functions.

### Additional changes

* **Fixed default configuration for incident subheading:** Incident subheadings in the incidents list and incident details will be as intended without additional configuration changes.

## 3.8.2

2026-03-09

### Highlights

* **Added new settings for tuning the turnout presentation for TETRA user:** We have added new settings to support the customization of the turnout for TETRA users in a future release of Vehicle Services.


## 3.8.0

2026-02-17

### Highlights

* **Improved logging of communication with the CAD:** Resolved an issue where logs from messages sent to the CAD occasionally could be missed and affect our support response times.


## 3.7.1

2026-02-03

### Highlights

* **Pager functionality backend support**: Added the server-side support for receiving position updates from Central Services mobile and forwarding them to the CAD as AVL data.
* **Added support for formatting GD92 Text messages:** GD92 Text messages that are sent by the CAD can now include line breaks and these will be rendered correctly.

## 3.7.0

2025-12-29

### Highlights

* **Re-structured the application structure:** The Central Services Web app was reworked to be more robust, the breadcrumb system was notably cleaned up to be more visually consistent.

### Additional changes

* **Fixed an issue with PDF viewing in the Info App:** Viewing PDFs inside the Info App could sometimes have visual glitches if the page was reloaded while viewing the PDF. This should now be fixed.
