## 4.7.0

2026-07-14

### Highlights

* **Fixed an issue where images with capitalized file extensions (such as .PNG) could not be viewed:** Images with capitalized file extensions now display correctly instead of appearing as generic files.

### Additional changes

* **Corrected PDF orientation button labels:** The PDF orientation buttons now display the correct labels, making it easier to choose the intended action for the user.

## 4.6.0

2026-07-06

### Highlights

* **Users can now see all assigned resources for each incident:** The list displays callsigns and shows whether each resource is mobilised or demobilised, sorted for quick identification and color-coded for clarity
* **Fixed an issue where accept/dismiss buttons disappeared after demobilizing recipients:** Now, when one recipient is demobilized from a case, the accept/dismiss buttons remain visible for other active users as expected

### Additional changes

* **Fixed a crash when loading large PDF files:** Previously, loading large PDF documents in the info app on Vehicle Services could cause system instability. We have now optimized the PDF viewer in the app to be more efficient, so this should no longer happen

## 4.5.0

2026-06-15

### Highlights

* **Resolved an issue with message permissions:** Users without the proper permissions will no longer see the stop message button, preventing unauthorized message sending and improving user experience

## 4.3.0

2026-06-01

### Highlights

* **Improved system monitoring and reporting for better support:** Added enhanced logging to help support teams diagnose and resolve common problems more quickly.

## 4.2.0

2026-05-26

### Highlights

* **Fixed a rare issue with group permissions updates:** Resolved a rare issue where The Admin app could incorrectly reject app permission updates for a user group due to license availability.

## 4.1.0

2026-05-11

### Highlights

* **Added the new Closures app:** Users can now add, view and edit road restrictions, such as closures and blockages. These restrictions are visible in Vehicle Services' Navigation app and routes will automatically avoid affected areas to improve routing reliability and situational awareness.
* **Expanded incident management options for Admin users:** Administrators can now view all active incidents for improved oversight and response coordination. They can see incident details, turnout, as well as participate in the associated incident chat groups and incident command functions.

### Additional changes

* **Newest items now appear at the top:** The lists in chat and command apps now show the most recent items first, making it easier to stay up to date

## 4.0.0

2026-04-20

### Highlights

* **Easier to manage incidents in CS web:** You can now accept or dismiss an incident directly from the incident view
* **Better visual design for the incident list:** Labels for incident status (active, pending, dismissed) and list items have been updated for a clearer and more consistent look, making information easier to understand
* **A warning banner appears when a user attempts to change status without a callsign:** The app informs users that a callsign must be selected before updating status.
* **The status selection menu has an updated design:** The app presents a clearer and more user-friendly way to choose a status.

### Additional changes

* **Added options for organizations to customize the incident flow:** Organizations can now choose to hide the dismiss button if they prefer when receiving a new incident.
* **Templated headings and subheadings:** The main titles and descriptions for incidents can now be customized via settings to better match organizational workflows and needs.

## 3.8.2

2026-03-09

### Highlights

* **Improved map experience:** Fixed an issue on web, where the map on the main and incident page could appear completely blue.
* **Fixed map not showing properly in the web portal** After allowing location permission, the map now displays your position correctly
* **Improved map behavior when sending status:** The map no longer reloads and appears broken when sending a status.

## 3.8.1

2026-02-24

### Highlights

* **The call sign folder structure is now visible in the call sign list:** Call signs can now be viewed and searched by folder when selecting one.

### Additional changes

* **Chat app improvements:** The Chat App has been improved to better handle call sign changes.


## 3.7.1

2026-02-03

### Highlights

* **Improved the Chat app stability:** The Chat App was rewritten to be more robust and handle better loss of connection.
* **Added more styling options to chat messages:** We have added support for sending and receiving messages with richer styling options such as bold and italics in the Chat App.

### Additional changes

* **Added text showing when there are no incidents in the Incident Command app:** You will now see a text saying "No incident available" when there is none in the Incident Command app.
* **Fixed issue with message display:** Fixed an issue where the Chat App would display messages with new lines as a long single line instead, which made them harder to read

## 3.7.0

2025-12-29

### Highlights

* **Re-structured the application structure:** The Central Services Web app was reworked to be more robust, the breadcrumb system was notably cleaned up to be more visually consistent.

### Additional changes

* **Fixed an issue with PDF viewing in the Info App:** Viewing PDFs inside the Info App could sometimes have visual glitches if the page was reloaded while viewing the PDF. This should now be fixed.
