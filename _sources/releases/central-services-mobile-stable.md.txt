## 2.4.0

2026-06-15

### Highlights

* **Resolved an issue with message permissions:** Users without the proper permissions will no longer see the stop message button, preventing unauthorized message sending and improving user experience

## 2.3.0

2026-06-01

### Highlights

* **Fixed an issue where tapping an incident notification did not show incident details:**  Tapping an incident notification now opens the correct incident details instead of the incident list.
* **Fixed an issue where opening a new message notification did not show the chat group:** Tapping a message notification now takes users directly to the conversation, even after the app has been closed.
* **Improved notifications for images sent by administrators:** Notifications for images sent by administrators without a callsign now display the sender's name instead of their email address.

### Additional changes

* **Improved system monitoring and reporting for better support:** Added enhanced logging to help support teams diagnose and resolve common problems more quickly.


## 2.2.0

2026-05-26

### Highlights

* **General security and performance improvements:** Ongoing improvements have been made to enhance system security, stability, and performance.

## 2.1.0

2026-05-11

### Highlights

* **Added the new Closures app:** Users can now add, view and edit road restrictions, such as closures and blockages. These restrictions are visible in Vehicle Services' Navigation app and routes will automatically avoid affected areas to improve routing reliability and situational awareness.
* **Expanded incident management options for Admin users:** Administrators can now view all active incidents for improved oversight and response coordination. They can see incident details, turnout, as well as participate in the associated incident chat groups and incident command functions.

### Additional changes

* **Newest items now appear at the top:** The lists in chat and command apps now show the most recent items first, making it easier to stay up to date
* **Cleaner mobile document viewing:** Resolved issue with having two back buttons when viewing PDFs on mobile devices.

## 2.0.0

2026-04-20

### Highlights

* **You can now see and change your current status and callsign in the top bar:** This makes it easier for users to stay informed and in control of their status and vehicle assignment. By clicking the new buttons, the user can at any time or place in the app change their callsign or status.
* **Easier to manage incidents in CS mobile:** You can now accept or dismiss an incident directly from the incident view.
* **Better visual design for the incident list:** Labels for incident status (active, pending, dismissed) and list items have been updated for a clearer and more consistent look, making information easier to understand
* **A warning banner appears when a user attempts to change status without a callsign:** The app informs users that a callsign must be selected before updating status.

### Additional changes

* **Added options for organizations to customize the incident flow:** Organizations can now choose to hide the dismiss button if they prefer when receiving a new incident.
* **Templated headings and subheadings:** The main titles and descriptions for incidents can now be customized via settings to better match organizational workflows and needs.
* **Removed skip button from onboarding:** If customers skipped a permission check on IOS first time, they would not be able to enable it later.
* **Fixed double notification issue on iOS:** On IOS, a notification could be shown twice; one as critical, one normal. This has been fixed.

## 1.5.1

2026-03-09

### Highlights

* **Improved map:** Fixed an issue where the map on the home page and incident page would sometimes be blue.
* **Better handling of permissions:** Fixed a bug where the user would not be alerted properly if they didn't have the correct permissions.
* **Fixed map not showing properly** After allowing location permission, the map now displays your position correctly
* **Improved map behavior when sending status:** The map no longer reloads and looks broken when you send a status

### Additional changes

* **Improved UI:** Fixed an issue in the call-sign folder selection where the search bar could appear too large for the screen.
* **Fixed notifications:** Fixed an issue where when a user logs out then back in as another user, they would receive double notifications.

## 1.5.0

2026-02-24

### Highlights

* **Better Info App translation:** "Current" tab was changed to "Temporary"
* **The call sign folder structure is now visible in the call sign list:** When choosing a call sign, you'll be able to view and search the call signs by folder.

### Additional changes

* **Chat app improvements:** The Chat App has been improved to better handle call sign changes.

## 1.4.2

2026-02-03

### Highlights

* **Improved the Chat app stability:** The Chat App was rewritten to be more robust and handle better loss of connection.
* **Added more styling options to chat messages:** We have added support for sending and receiving messages with richer styling options such as bold and italics. 
* **Improved the app performance and offline behavior:** The app performance has been significantly improved through the use of caching, which also adds that it is now possible to keep accessing the online data (turnout, info) that was previously viewed even if the device goes offline or with low connectivity
* **Pager functionality for Android**: Implemented continuous location sharing to the CAD (as AVL data) on CS Android only based on current user status. 
* **Added one more favorite app to the bottom bar in CS mobile:** User now can select up to 3 favorite apps to show in the bottom bar

### Additional changes

* **Fixed issue with message display:** Fixed an issue where the Chat App would display messages with new lines as a long single line instead, which made them harder to read
* **Fixed an issue with missing data:** In previous versions, the app could fail at displaying the favourites apps in the bottom bar as well as the notification settings. This could be confusing to the user as it seemed like these were reset. This new version should fix this issue.

## 1.4.1

2025-12-29

### Highlights

* **Improved the offline and low-connection functionality:** The Mobile app now stores more data locally on the device to better handle the scenarios in which connectivity is suboptimal, the data is shown in its previous state until connectivity is back again.

### Additional changes

* **Fixed issue with favourite apps and notification settings not showing correctly:** The previous versions had an issue where the favourite apps and notification settings would not show until the app was restarted, which could lead the user to think they were reset. This is now fixed.
* **Stability and performance improvements:** The general stability and performance of the app was improved.
