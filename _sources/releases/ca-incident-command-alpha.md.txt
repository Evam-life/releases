# Vehicle Services: Incident Command App changelog - Alpha

`````{warning}
You are viewing the Alpha releases of the Incident Command Certified App.
`````

## 1.1.6

2026-10-23

### Highlights

* **Added support for US English, with imperial units by default:** The Command App now supports devices set to US English. If your organisation has not chosen a unit system, devices set to US English now show line and area measurements in imperial units. Before, metric units were always the default. A unit system set in your organisation's settings still takes priority.

## 1.1.5

2025-08-15

### Highlights

* **Improved the overall performance of the app:** We improved the algorithm for synchronising features on the Command App map with the Vehicle Services navigation map. This results in less redraws on the Navigation map and lowers the CPU load on the system when there are many features to be displayed on the map for an incident.

### Additional changes

* **Fixed an issue where drawn features would not be removed:** In some cases, the drawings for an incident may have not been removed after demobilisation. This should now be fixed.
